動作環境・使い方（Bluefy版）
  1. このページを HTTPS の URL で、iPhone の Bluefy アプリで開きます。
  2. Bluefy の設定で watchAdvertisements（周囲のアドバタイズ監視）を有効にし、Bluetooth の許可を与えてください。
  3. 「監視開始」から受信を開始してください。対応信号機の近くで受信を待ちます。複数の交差点を受信した場合は一覧から選択できます。

受信方式は3つあります。「周囲をまとめて監視（Bluefy）」は Bluefy 独自の navigator.bluetooth.watchAdvertisements() を使い、メーカーID 0x01CE のデータを解析します。「周囲をまとめてスキャン」は Chrome の実験的機能 requestLEScan() 用、「デバイスを選んで広告を監視」は requestDevice() + device.watchAdvertisements() 用で、いずれも GATT 接続は行いません。通常は対象外メーカーのデータを破棄しますが、デバッグモードでは受信確認のため表示します。

PICS信号機が近くにない場合は「デバッグモード」をオンにして「監視開始」を押してください。受信イベント数が増えればBLEアドバタイズを受信できています。0件のままでもスキャン失敗とは限りません。周囲にアドバタイズを送信するBLE機器があるか、権限やBluetooth設定を確認してください。

ページを非表示にすると受信を停止します。再開するときは「監視開始」を押してください。5秒以上信号データが届かない場合は「更新なし」と表示します。監視中は Bluefy の画面スリープ防止APIが使える場合に画面を暗くしません。

データはこのページ内だけで処理し、サーバーには送信しません。再読み込みや実機・デモの切り替えで受信データは消去されます。
